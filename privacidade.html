Política de Privacidade

Última atualização: Outubro de 2026

1. Dados que acessamos e coletamos

O Grana Clara acessa apenas as informações estritamente necessárias para o funcionamento da sincronização na nuvem:

  • Informações de Perfil e E-mail: Acessadas apenas para identificar o usuário ativo no aplicativo desktop.
  • Arquivos do Google Drive: O aplicativo solicita acesso restrito ao Google Drive (escopo drive.file), o que significa que ele só pode visualizar, editar e criar arquivos que o próprio aplicativo criou (especificamente, o arquivo granaclara_dados.json na pasta Grana Clara). Ele não tem acesso aos seus outros arquivos pessoais.

2. Onde os dados são armazenados

O Grana Clara é um aplicativo 100% local. Seus dados financeiros não são enviados para nenhum servidor de terceiros, banco de dados externo ou para o desenvolvedor. Eles permanecem no seu computador físico e no seu próprio Google Drive.

3. Compartilhamento de dados

Nenhuma informação pessoal ou dado financeiro é compartilhado com terceiros. Nós não vendemos, alugamos ou repassamos seus dados.

4. Conformidade com a Política de Dados de Usuário do Google (Limited Use)

O uso e a transferência das informações recebidas das APIs do Google pelo Grana Clara para qualquer outro aplicativo estarão de acordo com a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use).

5. Como revogar o acesso

Você pode desconectar sua conta a qualquer momento clicando no botão "Desconectar" dentro das configurações do aplicativo Grana Clara. Além disso, você pode revogar o acesso do aplicativo diretamente pela sua conta do Google acessando myaccount.google.com/permissions.
